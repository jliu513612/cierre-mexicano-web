# Tax Certeza — Sitio web oficial

Sitio oficial de **Tax Certeza** (`https://taxcerteza.mx/`), software de escritorio para Windows enfocado en el cierre fiscal mensual para contadores y despachos en México.

## Qué incluye este sitio

- **Portada y descarga**: [https://taxcerteza.mx/](https://taxcerteza.mx/) — información del programa para Windows (64 bits), prueba de 30 días sin registro, descarga verificada por SHA-256 y manual de usuario.
- **Herramientas gratuitas en navegador**: [https://taxcerteza.mx/herramientas/](https://taxcerteza.mx/herramientas/) — calculadora de IVA del mes, validador de RFC, consulta de lista 69-B (EFOS), valor de la UMA, tipo de cambio DOF, fecha límite de complemento de pago (REP), factura con retenciones, calendario del día 17 y diagnóstico del mes.
- **Recursos fiscales**: [https://taxcerteza.mx/blog/](https://taxcerteza.mx/blog/) — guías prácticas sobre CFDI, IVA, ISR, DIOT y plazos del SAT con fundamento legal.
- **Centro de ayuda**: [https://taxcerteza.mx/ayuda/](https://taxcerteza.mx/ayuda/) — documentación paso a paso y memoria de cálculo.
