# CFDI ilegibles

*Flujo de caja y salud del cliente › Tarjeta de salud del cliente*

XML registrados como ilegibles (excluyendo salidas propias); señal sin monto

## Dónde se ve en el programa

- Tablero › «Salud del cliente…» › tabla de señales › renglón «CFDIs ilegibles» › columna «N» (monto «sin monto») — [cómo se usa](../uso/19-salud-del-cliente.md)
- Tablero › línea «Salud de datos» bajo la tabla de clientes › «N ilegibles» (rojo si hay; el tooltip lista los archivos) — [cómo se usa](../uso/06-tablero.md)
