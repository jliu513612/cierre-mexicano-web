# Utilidad fiscal neta del ejercicio para la CUFIN

*Cierre anual › CUFIN y CUCA*

El resultado fiscal menos el ISR, los no deducibles (sin fracciones VIII/IX del 28) y la PTU pagada; puede ser negativa.
