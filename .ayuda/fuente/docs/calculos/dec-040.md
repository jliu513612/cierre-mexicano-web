# Estado del plazo del REP: vencido, urgente o en tiempo

*Banco y conciliación › Complementos de pago: plazos*

## Cuándo aplica

Al revisar los cobros de facturas PPD que todavía no tienen complemento de pago: el programa dice, para cada uno, si el plazo ya venció, si está por vencer o si aún hay tiempo.

## Ejemplo

*Datos inventados para ilustrar. Las cifras las calcula el programa con su propio motor de cálculo; no son de ningún cliente.*

| | |
|---|---|
| Fecha de revisión | 03/03/2026 |
| Cobro de enero | 20/01/2026 |
| Cobro de febrero | 25/02/2026 |
| Cobro de marzo | 01/03/2026 |

## Cálculo paso a paso

1. Fecha de revisión: 03/03/2026. Días restantes = fecha límite − fecha de revisión. Vencido si es negativo; urgente si quedan 3 días o menos; en tiempo si quedan más.
2. Cobro de enero (20/01/2026): límite 05/02/2026, venció hace 26 días → Vencido.
3. Cobro de febrero (25/02/2026): límite 05/03/2026, quedan 2 días → Urgente.
4. Cobro de marzo (01/03/2026): límite 05/04/2026, quedan 33 días → En tiempo.

**Resultado**

| | |
|---|---|
| Cobro de enero (20/01/2026) | Vencido |
| Cobro de febrero (25/02/2026) | Urgente |
| Cobro de marzo (01/03/2026) | En tiempo |

## Qué hace el programa

Vencido si ya pasó el límite; urgente si quedan 3 días o menos; normal en otro caso

## Parámetros que usa

- **Días para considerar urgente un complemento: 3 días o menos** días naturales
  - Cómo se mide: Fecha límite menos la fecha de revisión (hoy, salvo otra fecha de corte). Negativo: vencido; de 0 a 3: urgente; más de 3: en tiempo.
  - Vigencia: Fijo.
  - ¿Se puede cambiar?: Fijo en esta versión.
  - Fuera del rango o si falta: —

## Dónde se ve en el programa

- Cierre › «Ver cálculo» › Memoria de cálculo › doble clic en «PPD cobradas sin REP: …» › columna «Plazo» — [cómo se usa](../uso/13-cierre-mensual.md)

## Fundamento y excepciones

**Fundamento:** RMF 2026, regla 2.7.1.32

**Fuente oficial:** [Resolucion Miscelanea Fiscal para 2026 (y sus Anexos)](https://dof.gob.mx/nota_detalle.php?codigo=5777217&fecha=28/12/2025) (texto vigente para 2026, publicada DOF 28-12-2025, consultado el 14/10/2026)

- El mismo día 5 todavía no está vencido: aparece como urgente (quedan 0 días). Vence a partir del día 6.
- Los días se cuentan naturales, incluidos sábados, domingos y festivos.
- En el programa, la fecha de revisión es el día en que se corre el cierre; el mismo cobro puede pasar de «en tiempo» a «urgente» o «vencido» en una corrida posterior.
