# ISN: entidad federativa a partir del código postal

*Nómina › Impuesto sobre nómina*

La entidad se deduce de los dos primeros dígitos del código postal (catálogo SEPOMEX).

## Dónde se ve en el programa

- Nómina › «Abrir nómina del periodo…» › pestaña «Empleados» › «C.P.:» › «Detectar por C.P.» › llena «Estado (ISN):» — [cómo se usa](../uso/11-nomina.md)
