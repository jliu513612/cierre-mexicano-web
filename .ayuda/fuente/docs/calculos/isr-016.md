# Pago provisional estimado del mes

*Cierre mensual e ISR › Acumulación de meses anteriores*

El ISR acumulado del mes menos los pagos acumulados anteriores; nunca negativo. Ese es el estimado: si del mes hay acuse capturado se toma lo declarado, y si hay evidencia de pago se toma lo pagado (pago más retención); el importe que resulte es el que se acumula para los meses siguientes.

## Dónde se ve en el programa

- Cierre › «Ver cálculo» › Memoria de cálculo › «(−) Pagos provisionales anteriores» y campo «Pagos prov. pagados:» — [cómo se usa](../uso/13-cierre-mensual.md)
- SAT vs Libros › columnas «ISR calc.», «ISR decl.» y «Δ ISR» — [cómo se usa](../uso/15-sat-vs-libros.md)
