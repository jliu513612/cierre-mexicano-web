# Tasa de IVA con que se clasifica cada comprobante en la DIOT

*CFDI e IVA › Tasas*

Cada comprobante recibe una tasa principal para la DIOT. Si trae IVA, se clasifica al 8% solo cuando declara tasa del 8% y ninguna del 16%; en cualquier otro caso, al 16%. Si no trae IVA, se mira la tasa que declara: si algún traslado trae una tasa y un importe que no cuadran entre sí (por ejemplo, base de 500 al 16% con IVA en cero), el comprobante queda marcado como contradictorio y el archivo de carga de la DIOT no se genera hasta que lo revises; si cuadran, se respeta la tasa declarada (16%, 8% o 0%) aunque el IVA redondee a cero, y solo se considera exento cuando no declara ninguna tasa. Esa tasa principal no se lleva todo el importe: si el comprobante mezcla tasas, la base se reparte entre los renglones según cada traslado, y lo que el desglose no explica (por ejemplo, un descuento) queda en la tasa principal.
