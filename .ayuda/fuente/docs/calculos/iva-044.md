# Tipo de tercero en la DIOT: nacional, extranjero o global

*CFDI e IVA › DIOT*

El tipo de tercero de cada proveedor en la DIOT se decide por su RFC: con el RFC genérico de extranjero (XEXX010101000), o sin RFC, va como proveedor extranjero (05); con el RFC genérico de público en general (XAXX010101000), como proveedor global (15); con un RFC que tiene la estructura de un RFC mexicano, como proveedor nacional (04); y cualquier otro valor, como extranjero. Para un proveedor extranjero la DIOT exige número de identificación fiscal, nombre y país: si falta alguno, el archivo de carga no se genera: la hoja de trabajo indica qué renglón y qué dato faltan.
