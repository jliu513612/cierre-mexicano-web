# Flujo de efectivo: saldo inicial de bancos

*Flujo de caja y salud del cliente › Flujo de caja a 13 semanas*

El saldo inicial es el último saldo final que aparece en los estados de cuenta cargados para cada cuenta, hasta el mes del corte. Las cuentas en otra moneda se convierten a pesos con el tipo de cambio, que se muestra en la fila; si no hay tipo de cambio, esa cuenta se muestra aparte y no se suma al saldo. Si el saldo de un estado de cuenta no se pudo leer, tampoco se suma ni se toma como cero: se avisa aparte. Si el estado más reciente tiene más de un mes de antigüedad aparece un aviso de saldo viejo, y si no hay ningún estado de cuenta el saldo inicial sale en 0 con el aviso de que falta el dato.
