# EFOS: situaciones de la lista 69-B que sí permiten acreditar el IVA

*CFDI e IVA › Requisitos del acreditamiento*

## Cuándo aplica

Cuando un proveedor aparece en la lista del SAT de operaciones presuntamente inexistentes (art. 69-B del CFF): solo la etapa de definitivo quita el IVA acreditable, y solo de las facturas posteriores a su publicación.

## Ejemplo

*Datos inventados para ilustrar. Las cifras las calcula el programa con su propio motor de cálculo; no son de ningún cliente.*

| | |
|---|---|
| Periodo | marzo 2026 |
| Proveedor 1: en etapa de presunto | factura PUE, subtotal $1,000.00, IVA $160.00 |
| Proveedor 2: desvirtuó la presunción | factura PUE, subtotal $1,000.00, IVA $160.00 |
| Proveedor 3: obtuvo sentencia favorable | factura PUE, subtotal $1,000.00, IVA $160.00 |
| Proveedor 4: definitivo publicado el 20 de marzo; factura del 12 de marzo | factura PUE, subtotal $1,000.00, IVA $160.00 |
| Proveedor 5: definitivo publicado el 16 de febrero; factura del 10 de marzo | factura PUE, subtotal $1,000.00, IVA $160.00 |

## Cálculo paso a paso

1. Proveedor 1: en etapa de presunto: el IVA de $160.00 sí se acredita.
2. Proveedor 2: desvirtuó la presunción: el IVA de $160.00 sí se acredita.
3. Proveedor 3: obtuvo sentencia favorable: el IVA de $160.00 sí se acredita.
4. Proveedor 4: definitivo publicado el 20 de marzo; factura del 12 de marzo: el IVA de $160.00 sí se acredita.
5. Proveedor 5: definitivo publicado el 16 de febrero; factura del 10 de marzo: la factura es posterior a la publicación del definitivo, su IVA de $160.00 no se acredita.
6. IVA acreditable de marzo: $640.00, sobre una base de $4,000.00.

**Resultado**

| | |
|---|---|
| IVA acreditable de marzo | $640.00 |
| IVA no acreditable por proveedor definitivo | $160.00 |

## Qué hace el programa

Presunto, desvirtuado o con sentencia favorable SÍ acreditan; solo definitivo excluye.

## Dónde se ve en el programa

- CFDIs › rejilla de comprobantes › punto de «Status» «Estuvo en 69-B y DESVIRTUÓ (o ganó sentencia): deduce» o «En 69-B como PRESUNTO: hoy deduce» — [cómo se usa](../uso/07-cfdis.md)
- CFDIs › «Revisar ▾» › «EFOS (lista 69-B)» › resumen «… en lista SIN exclusión (presunto / no localizado): hoy deducen» — [cómo se usa](../uso/07-cfdis.md)

## Fundamento y excepciones

**Fundamento:** CFF, art. 69-B

**Fuente oficial:** [Codigo Fiscal de la Federacion](https://www.diputados.gob.mx/LeyesBiblio/pdf/CFF.pdf) (texto vigente para 2026, última reforma DOF 09-04-2026, consultado el 14/10/2026)

- Una factura de un proveedor definitivo con fecha igual o anterior a la publicación del definitivo sí se acredita.
- Si el proveedor es definitivo pero no se conoce la fecha de publicación, la factura no se excluye: se acredita y queda señalada para revisarla a mano.
- La misma regla se aplica a los pagos de facturas en parcialidades documentados con complemento de pago.
