# Contabilidad electrónica: validación del código agrupador del catálogo de cuentas

*Contabilidad y declaraciones › Catálogo de cuentas*

Si alguna cuenta no tiene código agrupador, el catálogo no se emite. Si un código agrupador no existe en el catálogo oficial, el archivo se marca inválido; en el cierre ese catálogo y su marca se retiran, tampoco se emite la balanza, y el cierre continúa informando el motivo.

## Dónde se ve en el programa

- «☰ Más» › «Catálogo de cuentas» › pestaña «Cuentas» › aviso «Faltan códigos agrupadores: … el catálogo y la balanza de contabilidad electrónica de este cliente NO se generan» — [cómo se usa](../uso/16-polizas.md)
- Cierre › «Ver ▾» › «Ver detalles...» › «Hallazgos del auditor» › columna «Hallazgo» › «La contabilidad electronica de este periodo NO se genero» — [cómo se usa](../uso/13-cierre-mensual.md)

## Fundamento

**Fundamento:** RCFF, art. 33; CFF, art. 81, fr. V
