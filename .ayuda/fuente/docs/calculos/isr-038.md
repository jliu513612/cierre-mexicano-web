# Base gravable: resultado fiscal menos pérdidas amortizadas

*Cierre anual › Pérdidas fiscales*

El resultado fiscal menos las pérdidas amortizadas; con resultado cero o negativo no se amortiza y ese resultado es la pérdida del ejercicio.

## Dónde se ve en el programa

- Cierre Anual › «Papel de trabajo ANUAL (Excel)» › hoja «Conciliación fiscal» › «Base gravable (tras pérdidas)» — [cómo se usa](../uso/17-cierre-anual.md)
- Cierre Anual › «Papel de trabajo ANUAL (Excel)» › hoja «Conciliación fiscal» › «Pérdida fiscal DEL ejercicio (a registrar para amortizar en los siguientes)» — [cómo se usa](../uso/17-cierre-anual.md)
